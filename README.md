# Databricks Training - Data Engineering Track

## 📌 Overview

This repository contains my learning and hands-on practice during the Databricks/Data Engineering training program conducted in collaboration with Capgemini.

## 🎯 Objective

To gain practical knowledge in:

* SQL
* Data Engineering concepts
* Databricks platform
* Real-world data processing

## 🗂️ Structure

* Week-wise organization
* Each week contains daily tasks and solutions
* Includes SQL scripts, outputs, and explanations

## 🚀 Commitment

* 6 hours/day
* 6 days/week
* 6 weeks (~200 hours)
